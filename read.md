# 🌕 LunaMeet — Будущее билетов на события. Присоединяйтесь к революции!

> **LunaMeet** — это не просто билетный сервис. Мы создаём экосистему, которая изменит способ, как люди покупают билеты и посещают мероприятия. Мы предлагаем не просто покупку, а умные билеты, персонализированные рекомендации и уникальный опыт для каждого пользователя.

## 📣 Почему инвестировать в LunaMeet?

Мы предлагаем **новаторскую платформу**, которая будет конкурировать с крупнейшими игроками на рынке, такими как **kvitki.by**. В отличие от существующих решений, **LunaMeet** решает реальные проблемы как для пользователей, так и для организаторов мероприятий.

### 🔥 Уникальные фишки, которые отличают нас от конкурентов:

1. **Умные QR-билеты**:
    - **Живой статус**: билеты меняют свой статус в реальном времени (Активен → Использован → Заблокирован).
    - **Интерактив**: в зависимости от времени, сканируемый QR-код показывает различный контент:
        - До мероприятия: расписание, тизеры.
        - Во время: статус входа.
        - После: форма для отзыва, галерея, бонусы.
        
2. **Персонализированные рекомендации**:
    - **Индивидуальные предложения**: алгоритмы, основанные на интересах и поведении пользователей, предлагают события, которые им могут понравиться. Простой алгоритм "люди, которые были на X, часто идут на Y".
    - **Геолокация**: рекомендации по ближайшим событиям с учетом местоположения.

3. **Мобильное приложение** (.NET MAUI):
    - Полноценное кроссплатформенное приложение для Android/iOS с функциями покупки билетов, сканера QR, а также геолокации событий.
    - Уведомления и оффлайн-доступ к билетам.

4. **AI для аналитики и прогнозирования**:
    - В ближайших планах добавление рекомендаций с помощью **ML.NET** на основе посещений, предпочтений и геолокации пользователей.
    - Прогнозирование трендов и интересов, которые помогут организаторам более точно настроить маркетинг.

5. **Платформа для организаторов**:
    - Простая и удобная панель управления для организаторов мероприятий, включая создание событий, анализ продаж, управление входом через QR-сканер, а также экспорт данных.

## 🏗 Архитектура проекта

LunaMeet использует **Clean Architecture** и построен на современных технологиях:

LunaMeet/ │ ├── LunaMeet.API # Web API (.NET Minimal API) ├── LunaMeet.Application # CQRS, бизнес-логика, MediatR ├── LunaMeet.Domain # Сущности, enum, value-объекты ├── LunaMeet.Infrastructure # Сервисы: QR, Email, Logs ├── LunaMeet.Persistence # EF Core + PostgreSQL, миграции ├── LunaMeet.Mobile # .NET MAUI-приложение └── LunaMeet.Tests # Юнит и интеграционные тесты



### 🧩 Технологии:
| Компонент       | Технологии                        |
|-----------------|-----------------------------------|
| Backend         | ASP.NET Core 8, Minimal API       |
| База данных     | PostgreSQL + EF Core              |
| Бизнес-логика   | MediatR + CQRS + AutoMapper       |
| QR-коды         | QRCoder                           |
| Аутентификация  | ASP.NET Identity + JWT            |
| Мобильное       | .NET MAUI                         |
| Frontend (буд.) | Blazor / React                    |
| Realtime        | SignalR                           |
| Рекомендации    | ML.NET (в планах)                 |
| CI/CD           | GitHub Actions + Docker           |
| Хостинг         | Railway / Azure                   |
